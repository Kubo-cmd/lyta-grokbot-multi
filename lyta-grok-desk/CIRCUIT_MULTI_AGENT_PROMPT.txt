# Multi-agent layout (12 voters + 1 coordinator)

Coordinator agent (only executable): lyta-grok-desk-paper
- Wakes on the hourly trigger.
- Reads paper collateral.
- Reads BTC or ETH Papertrade market (change_1h, change_4h, change_8h, change_24h, 24h average, 24h range).
- Calls each voter-agent. Each voter returns {side: "long"|"short"|"pass", conv: number, reason: string}.
- Tallies. Requires 7+ on one side.
- Computes margin/notional. Stands down if below typical Papertrade mins (~10 USDC margin / ~$500 notional) — expected with $2–$6 paper.
- If already holding that coin, PORTFOLIO and the coordinator both pass / stand down.
- Logs every vote, then either [CONSENSUS] + [SIZING] or [STAND DOWN] with calculated vs required numbers.
- Expected and desired: with $2–$6 the desk logs votes then stands down for size on nearly every run. That is success, not a bug.
- Always emit: "This run is observation only. No trades executed."

Voter-agents (vote only, never call positions.open):

1. SCOUT — the last hour's move.
2. FILTER — the day's move, but only if bigger than 0.5%.
3. ANALYST — price against the 24-hour average.
4. PUMP_CHASER — a move bigger than 1% over the last 4 hours.
5. CONVICTION — votes only when the day's move and the last 4 hours agree.
6. MOMENTUM — the last 4 hours.
7. SCALPER — the last hourly candle.
8. CONTRARIAN — bets against a day's move bigger than 2%.
9. TREND — the 8-hour average against the 24-hour average.
10. RESEARCHER — where the price sits in its 24-hour range.
11. PORTFOLIO — the day's move, but passes if the desk already holds that coin.
12. EXECUTOR — price against the 8-hour average.

Replicate those twelve rules exactly. Do not improve, generalize, or add fingerprint / sniper / bundler logic.
