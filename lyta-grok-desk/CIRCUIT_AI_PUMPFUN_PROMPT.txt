## 12-Bot Voting Architecture (pump.fun signals)

Each bot's `bias` uses **pump.fun market data fields**:

| Field | Description |
|-------|-------------|
| `is_pump` | Boolean — early launch momentum |
| `analyst_score` | 0.0 – 1.0 — quality score |
| `rug_risk` | 0.0 – 1.0 — rug/sweep risk |
| `liquidity` | SOL/USD — protocol liquidity |
| `buys_5m` | Integer — buys in last 5 minutes |
| `price_change` | % — short-term pump/dump |
| `new_launch` | Boolean — newly launched pair |

| # | Bot | Conviction | Bias Rule | Hard Stop |
|---|-----|-----------|-----------|-----------|
| 1 | SCOUT | 0.75 | `is_pump && new_launch && rug_risk < 0.5` | -7% |

| 3 | ANALYST | 0.60 | `analyst_score > 0.5 && rug_risk < 0.4 && price_change > 0` | -6% |
| 4 | DEV_WATCH | 0.85 | `is_pump && buys_5m > 10 && price_change > 8` | -9% |

## Sizing & Risk Rules (same as Phase 1)

- **Risk:** 3% of collateral per trade (default)
- **Max leverage:** 5x
- **Micro-sizing:** $0.20 – $0.85 margin per trade
- **Dynamic scaling:** Read actual collateral; scale down if balance < $4
- **Hard caps:** If calculated margin < $0.25 or collateral < $2, stand down
- **Consensus bar:** 5/12 minimum

## Pump.fun Market Data Signals

The signal agent (`_signal_agent.ts`) computes:
- `is_pump` — true on early launch momentum (price rise + buys > threshold)
- `analyst_score` — composite quality score (sampler/sniper detection, wallet analysis)
- `rug_risk` — developer wallet concentration, top-10 holdings
- `buys_5m` — buys in last 5 minutes
- `price_change` — short-term % change
- `new_launch` — pair age < 30 min

## Papertrade Platform Rules

- Run with `circuit run --paper` for simulated funds
- Pump.fun signal data is simulated in paper mode; real pump.fun data is for later
- Use `papertrade.positions.open({ asset, side, margin, leverage })` for execution
- Read real balance: `papertrade.account.retrieve().collateral`
- Platform minimums: ≥ 10 USDC margin required; log gracefully if below
