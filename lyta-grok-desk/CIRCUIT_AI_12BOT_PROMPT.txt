# Circuit AI — Lyta Grok Bot Multi-Agent Desk (Phase 1: Paper Trading)

## Identity

Build a **12-personality autonomous trading desk** for Circuit AI's **Papertrade** venue
(synthetic perpetuals). The desk trades **BTC and ETH** only (stable, liquid markets for
tiny capital). The user has **$2 to $6 paper**. The #1 priority is **capital preservation
and data collection**, not profit.

## Platform Roles (IMPORTANT)

| Layer | Platform | Role | Always-On? |
|-------|----------|------|------------|
| **Grok Bot (Server)** | Managed cloud VM (xAI) | Routes tasks, coordinates, persistent state | ✅ Cloud keeps running |
| **OpenBot (Agents)** | Local desktop workspace | 12-bot voting, execution, risk | Runs on local machine |

The Grok Bot server **does NOT trade**. It routes to the 12-bot agent. The OpenBot
agent is the executable trading desk.

## The 12-Bot Voting Architecture

Each bot has a `bias` function and a `conviction` score. A token is traded only when
**at least 5 of 12 bots** agree on a side (long or short).

|---|-----|-----------|-----------|-----------|
| 1 | SCOUT | 0.75 | `change24h > 3 && liq > 1500 && rugScore < 0.55` | -7% |

| 3 | ANALYST | 0.60 | `change24h > 0 && rugScore < 0.4` | -6% |

## Sizing & Risk Rules

- **Risk:** 3% of collateral per trade (default)
- **Max leverage:** 5x
- **Micro-sizing:** $0.20 – $0.85 margin per trade
- **Dynamic scaling:** Read actual collateral; scale down if balance < $4
- **Hard caps:** If calculated margin < $0.25 or collateral < $2, stand down
- **Consensus bar:** 5/12 minimum (do NOT loosen — use 5)

## Papertrade Platform Rules (Circuit)

- **Run mode:** Use `circuit run --paper` for simulated funds
- **Open order format:** `papertrade.positions.open({ asset, side, margin, leverage })`
- **Read balance:** `papertrade.account.retrieve()` → collateral
- **Fallback:** If no Papertrade data, assume $6 collateral
- **Platform minimums:** Papertrade requires ≥ 10 USDC margin, ≥ 10,000 USDC notional
  — with tiny paper capital this is a known constraint; log gracefully and stand down
- **No real money** — this entire agent is paper-only

## Verbose Logging (Required)

Every run must log:
- Current collateral/available balance
- Market state: asset, price, change24h, volume, liquidity, rugScore
- Each bot's vote: PASS, LONG, or SHORT with reasoning
- Final tally: long=N short=M pass=P
- Consensus: N/12 agree
- Chosen side, margin, leverage, notional
- If standing down: reason (insufficient consensus, size too small, balance low)
