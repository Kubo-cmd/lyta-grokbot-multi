# 🚀 Circuit AI — Multi-Agent Startup Prompt (How to Use)

> These prompts are for **Circuit AI** (the desk builder).
> Use them in order, or pick the one that matches where you are.

## Option A — Start Fresh: Full Multi-Agent Setup

**Paste this into Circuit AI:**

```
I want to build a multi-agent trading desk with the platform separation:

1. GROK BOT (Server) — runs on managed cloud VM (xAI), always-on, routes tasks to agents
2. OPENBOT (Agents) — runs on local desktop workspace, 12 trading agents, MCP-native

Generate:
1. grok-bot-router agent — server router (code included)
2. lyta-grok-desk-paper agent — Circuit BTC/ETH paper trading agent (12-bot desk, phase 1)
3. lyta-grok-desk-spot agent — spot market agent (12-bot desk, phase 2)
4. lyta-grok-desk-signal agent — signal scanner
5. lyta-grok-desk-analyst agent — rug risk, liquidity evaluator
6. lyta-grok-desk-trader agent — execution (micro-sizing $0.20-0.85)
7. lyta-grok-desk-risk agent — risk management, stand-down
8. circuit.toml with multi-agent routing, 60s schedule triggers
9. index.ts router entry point
10. DESCRIPTION.md for each agent

Architecture:
- Grok Bot = server, do NOT trade, route to OpenBot agents
- OpenBot = local desktop, 12 agents, FIFO queues, shared files, ACP communication
- grok-bot (server) uses AGENT_TRIGGER on_trigger handler to route to correct agent
- OpenBot agents use the circuit run SDK for execution
```

**What you get:** A complete multi-agent workspace with routing, all 12 agents, and
the platform separation documented. Copy the generated files into `lyta-grok-desk/`.

## How the Multi-Agent Workflow Works

```
User message → Grok Bot (server) → routes to correct OpenBot agent
      ↓
OpenBot agent executes (trading, analysis, signal)
      ↓
Result returned to user (via Grok Bot server)
```

**Key rules:**
- Grok Bot never executes trades
- OpenBot agents never route tasks
- Each agent reads its own config from circuit.toml
- The 60s schedule trigger fires all agents; each checks its conditions and acts
- Micro-sizing is enforced by the trader agent: $0.20–$0.85 per trade
