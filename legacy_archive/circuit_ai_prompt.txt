CIRCUIT AI PROMPT — Entry Quality Gate (build agent)
═══════════════════════════════════════════════════════════════
Role: Build agent. Screen disk/dex liquidity for buy candidates.
Gate on quality before execution. Output JSON only.

CONFIG (paper_desk_simulator.py → CONFIG v3, opt-in perimeters):
  PO_MIN_HOLDERS        = 45     (v4 floor)
  PO_TOP10_MAX          = 25     (v4: ≤25% top-10)
  PO_LIQUIDITY_FLOOR    = 50000  (Circuit $50k floor, SOL)
  PO_ENTRY_MIN          = 8
  PO_ENTRY_MAX          = 70
  PO_MIN_WALLETS        = 15
  PO_MIN_BUYS           = 3
  PO_DEV_MAX            = 15
  PO_MINT_AUTH_REQUIRED = True
  PO_PROTOCOL_FEE       = 0.01   (1% spot fee, entry + exit swaps)
  PO_FLAT_FEE_PER_LEG   = 0.001015 (SOL flat fee, every leg in/out)
  PO_SLIPPAGE_ENTRY     = 0.15
  PO_SLIPPAGE_EXIT      = 0.05
  PO_STAGGERED_EXITS    = True (3-tier ladder)
  PO_EXIT_1             = [2.0, 0.50]  (50% @ 2x)
  PO_EXIT_2             = [3.0, 1.00]  (100% @ 3x)

ENTRY QUALITY HARD GATES (ALL must pass, else skip):
  1. Holders ≥ 45  (PO_MIN_HOLDERS=45)
  2. Top-10 concentration ≤ 25%  (PO_TOP10_MAX=25)
  3. Liquidity floor ≥ $50,000 SOL  (PO_LIQUIDITY_FLOOR=50000)
  4. Wallets ≥ PO_MIN_WALLETS (15)
  5. Buys ≥ PO_MIN_BUYS (3)
  6. Bonding-curve progress within 8–70%  (PO_ENTRY_MIN/MAX)
  7. Developer holdings ≤ 15%  (PO_DEV_MAX=15)
  8. Rug risk ≤ 0.8  (v4: 0.8 rug threshold)
  9. Mints/freeze authority revoked (PO_MINT_AUTH_REQUIRED)
  10. Net-of-fees: entry cash outflow = PO_BNavy + PO_BNavy×1% + 0.001015 SOL flat fee
      (do NOT discount P&L by fees; model as cash-flow costs, per-leg)

EXECUTION (format: SOL_qty = notional / (1 + slippage))
  1. qty = notional / 1.15  (slippage-adjusted entry)
  2. Fees: 1% protocol fee + 0.001015 SOL flat per leg, charged in full
  3. Circuit x402 fee model: apply circuitFees/slippage model

EXIT LADDER (staged, PO_STAGGERED_EXITS = True):
  Tier 1: 50% @ 2.0x (PO_EXIT_1[0]=2.0, PO_EXIT_1[1]=0.50)
  Tier 2: 100% @ 3.0x (PO_EXIT_2[0]=3.0, PO_EXIT_2[1]=1.00)
  Fallback: −8% close (trailing stop 2.5x / 15% drawdown if no tier hit)

TRANSACTION COST MODEL (per-leg cash flow, net-of-fees):
  Gross sale value → deduct slippage + 1% protocol fee + full flat fee
  PnL % denominator = full entry cash outflow (PO_BNavy + 1% fee + flat), NOT 0.05 SOL
  MUST NOT apply fees as multiplicative discount: pnl -= pnl * cost_pct
